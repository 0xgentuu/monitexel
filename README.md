Bill Splitter

Split a restaurant bill fairly in under a minute: shared items, VAT, tip, and a clear "who sends what to whom" at the end. Built for the group-chat reality of dinners with friends, with Naira as the default currency.

Features

Splitting

Add people and items, then choose exactly who shared each item
VAT and tip are shared in proportion to what each person ordered
Totals are exact to the kobo: the per-person amounts always add up to the grand total
Pick who paid and see who owes whom
History

Save any split with a name and come back to it later
Load an old split to edit it, or delete it when you no longer need it
Export all of your history to a JSON file and import it again on any device (duplicates are skipped, bad files are rejected)
Tools sidebar

Calculator with keyboard support
Currency converter using live rates (cached, with an option to type your own rate, which matters when the bank rate and the street rate differ)
Light and dark theme, and a choice of bill currency
Sharing

Send the summary to WhatsApp in one tap, copy it, or use the phone's share sheet
Tech

React, Vite, plain CSS with CSS variables (no UI libraries), and the ExchangeRate-API open endpoint for currency rates.
